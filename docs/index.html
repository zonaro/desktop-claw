New in Desktop Claw

Everything Desktop Plus has, plus a few more claws

Desktop Claw tracks Desktop Plus upstream and adds its own features on top. These are the ones exclusive to this fork.

Worktree tab

Git worktrees get first-class treatment: a toolbar dropdown to switch between them, and a dedicated Worktree tab that browses the checked-out tree as a file tree.

  • Create, rename, lock and delete linked worktrees from the app.
  • Switch worktrees from the toolbar, or open one in a new window.
  • Browse the working tree file by file, with syntax highlighting.

File editing

Open any file from the Worktree tab and edit it in place. No round trip through an external editor for a one-line fix.

  • Read-only preview with syntax highlighting, one click away from editing.
  • Save straight back to disk, so the change lands in your next commit.

Markdown editing & export

Markdown files open in a WYSIWYG editor instead of a wall of syntax, and can be exported for sharing.

  • Rich-text editing for headings, lists, links, tables and code blocks.
  • Rendered preview with interactive task-list checkboxes that write back to the file.
  • Export the document to a standalone HTML file or to PDF.

FTP deployments

Publish a repository to a web host over FTP or FTPS, straight from the app — handy for the static sites and small projects that never justified a CI pipeline.

  • Save multiple named targets per repository (host, port, user, remote path).
  • FTP or explicit TLS (FTPS), with credentials kept in the system keychain.
  • .gitignore-style exclude patterns so build junk stays local.
  • Live progress per file, and cancel an upload at any point.

OpenCode integration

Wire up the OpenCode CLI and let it draft your commit messages and review your work — running locally, against whichever model you have configured.

  • Generate commit messages from the staged diff.
  • Optionally produce a code review after each commit, written to the repository as Markdown.
  • Bring your own binary path, model and timeout. Disabled until you turn it on.

The same familiar workflow as GitHub Desktop, with the improvements power users kept asking for.

Search your history

Find any commit by title, message, tag, or hash, right in the History tab, no terminal required.

Multiple accounts & hosts

Sign in to multiple GitHub, Bitbucket, GitLab, Codeberg/Forgejo, or Gitea accounts at once. Clone, open pull requests, and see check status across all of them.

Visualize the commit graph

Switch the history into a graph view to see how branches and merges actually fit together.

Keep multiple stashes

Create and rename several stashes per branch, instead of being limited to a single slot.

Spot unpushed branches

Local-only branches (never pushed, or auto-deleted after a merged PR) get a clear warning indicator so nothing slips through.

Built for recognition

Speeds up your clicks with distinct icons for similar-looking buttons and red backgrounds on destructive actions.

The full list of additions

Every extra feature on top of GitHub Desktop, grouped by where you'll find it.

General improvements

  • Multi-account support (e.g. two GitHub accounts at once).
  • Rich integration with GitHub, Bitbucket, GitLab, Codeberg/Forgejo, and Gitea, including self-hosted instances. Basic git functionality in other platforms.
  • Multiple windows: open repositories side by side, or the same repo twice.
  • Allow overriding the external editor per repository.
  • Generate branch-name presets from an external script (e.g. append ticket number prefix).
  • Speeds up your clicks with distinct icons for similar-looking buttons and red backgrounds on destructive actions.
  • All GitHub / Microsoft telemetry is fully disabled.
  • Optional OpenCode CLI integration: generate commit messages from the staged diff, and optionally a Markdown code review after each commit.

Worktrees

  • Dedicated Worktree tab that browses the checked-out tree as a file tree.
  • Toolbar dropdown to switch between the main worktree and every linked one.
  • Create, rename, lock, prune and delete linked worktrees without leaving the app.
  • Open any worktree in a new window to work on two branches side by side.

Editing & deployment

  • Preview any file with syntax highlighting, then edit and save it in place.
  • WYSIWYG markdown editor for .md files, with headings, lists, links, tables and code blocks.
  • Rendered markdown preview with interactive task-list checkboxes that write back to the file.
  • Export markdown to a standalone HTML file or to PDF.
  • Deploy a repository over FTP or FTPS, with multiple saved targets per repository.
  • .gitignore-style exclude patterns, per-file upload progress, and cancellable uploads. Credentials are stored in the system keychain.

Repository list

  • “Pull all” button: fetch and pull every repository at once.
  • Allow showing the current branch name next to each repository.
  • Allow hiding the “Recent” section.
  • Customize the way repositories are grouped.
  • Pin repositories to the top of the list.

Branch list

  • Warning indicator on local-only branches (never pushed, or deleted after a PR).
  • Allow manually setting a custom default branch (used as the base for new branches).
  • Sort branches by “Recently updated” or “Alphabetical”.

History

  • Search commits by title, message, tag, or hash.
  • Switch to a Commit Graph view to visualize merge history.
  • Distinct styling for merge commits so they stand out less.
  • Double-click a single-file commit to open the file.
  • Amend commits that have already been pushed (use with caution!).
  • Delete pushed commits and tags (use with caution!).

Changes / Diff

  • Create and rename several stashes per branch, instead of being limited to a single slot.
  • Preview SVG files as images in the diff view.
  • Improved diff viewer with minimap and customizable font.
  • Option to permanently discard changes without using the trash, fast even with many files.

Windows 10 and 11

Look for these files under “Assets” on the release.

  • -windows-x64.exe64-bit x86 · Most PCs
  • -windows-arm64.exe64-bit ARM · Snapdragon / ARM devices
  • Run the installer and you're done — no admin rights required.
  • There's also an .msi build for enterprise deployment. It only registers a hook that installs the app at next login, so it needs a reboot to finish. Regular users should stick to the .exe.

macOS

Look for these files under “Assets” on the release.

  • -macOS-arm64.zipApple Silicon · M1 and newer
  • -macOS-x64.zip64-bit Intel
  • Unzip it and drag the app into your Applications folder.
  • If macOS reports it can't verify the app, open System Settings → Privacy & Security and click “Open Anyway”.

Linux

Look for these files under “Assets” on the release.

  • .debx86_64 · ARM64 · Debian, Ubuntu, Mint, Pop!_OS, Zorin, elementary OS
  • .rpmx86_64 · ARM64 · Fedora, RHEL, CentOS Stream, Rocky, AlmaLinux, openSUSE
  • .AppImagex86_64 · ARM64 · Any distro
  • gnome-keyring is required to store your credentials, and its daemon must be running at login.
  • The AppImage needs to be marked as executable before it will run, and it takes some manual setup for sign-in to work: create a desktop-claw.desktop entry and point the x-scheme-handler/x-github-desktop-auth MIME type at it. Prefer the .deb or .rpm if your distro supports them.

Desktop Claw doesn't update itself. It isn't distributed through Winget, Homebrew, or any distro repository — check the releases page now and then, or watch the repository on GitHub to get notified about new versions.

Versions are dates, not milestones. Each release is stamped from the moment it was built, in UTC, as {YY}.{dayOfYear}.{HHMM} — so a build from 13 August 2026 at 19:42 is 26.225.1942. A higher version is always a newer build.

Good to know

Not affiliated with GitHub

Desktop Claw is an independent community project. It is not an official GitHub product and is not endorsed by GitHub or Microsoft. GitHub Desktop is a trademark of GitHub, Inc.

A fork of a fork

Desktop Claw builds on Desktop Plus, which in turn forks GitHub Desktop. It tracks both upstreams and adds its own features on top.

No built-in updater

Unlike the official app, it doesn't update itself, and it isn't in any package manager. Watch the repository on GitHub so you know when a new release is out.

For devs and power users

It targets people comfortable with Git and a bit of setup. If you want the most polished, officially supported experience, the official GitHub Desktop app is a better choice.

No telemetry, fully open source

All GitHub and Microsoft telemetry is removed from the build. The full source is MIT-licensed and available on GitHub.
